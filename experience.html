ملف الإكسل

لم يُرفع بعد
اسحب ملف الإكسل هنا — أو انقر لاختياره xlsx · xls · xlsm · csv
صف واحد لكل مريض، والأعمدة تُعرف من عناوينها بالعربي أو الإنجليزي — لا يهم ترتيبها:
  • Patient Name / الاسم · File No. / رقم الملف · Package / نوع البكج · Branch / الفرع
  • Patient Feedback / تجربة المريض — نص الملاحظة كما قالها المريض.
  • Status / الحالة — Positive · No Answer · Negative · Neutral (أو إيجابي · لم يتم الرد · سلبي · محايد). إن لم يوجد العمود: من له ملاحظة يُحسب Positive، ومن ملاحظته فارغة يُحسب No Answer.
ربط الأعمدة — يُرشَّح تلقائيًا، ويمكنك تغييره
