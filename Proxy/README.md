# وسيط مباريات كورة تايم

خادم صغير يقف بين التطبيق و[API-Football](https://www.api-football.com)، يملك
المفتاح ويخزّن النتائج.

## لماذا

بلا وسيط يحتاج **كل مستخدم** مفتاحاً باسمه من API-Football. وأغلب من يحمّل
تطبيقاً لا يسجّل في خدمة ليستعمله — فيفتح تبويب المباريات، يجد ثلاث مباريات من
دوريات هامشية، ويحذف التطبيق.

ومع الوسيط يُطلب يوم المباريات **مرّة واحدة** ويُخدَم لكل المستخدمين من ذاكرة
الحوافّ:

| | بلا وسيط | مع الوسيط |
|---|---|---|
| ما يحتاجه المستخدم | تسجيل ومفتاح | لا شيء |
| استهلاك المفتاح | حصّة لكل مستخدم | طلب واحد لكل يوم، لكل المستخدمين |
| مكان المفتاح | داخل الجهاز | على الخادم وحده |

والمفتاح لا يُشحن داخل التطبيق حيث يُستخرج من الحزمة بسهولة.

## الحساب

التطبيق يعرض ١٥ يوماً (‏٤− إلى ١٠+). المباريات الجارية تُحدَّث كل دقيقة:

```
١٤ يوماً × مرة كل ٦ ساعات   =    56 طلباً يومياً
اليوم × مرة كل دقيقة        = 1,440 طلباً يومياً
                              ─────────────────
                              ~1,500 طلب يومياً — لعدد غير محدود من المستخدمين
```

| خطة API-Football | الحصّة | تكفي؟ |
|---|---|---|
| مجانية | ١٠٠/يوم | الجدول نعم، والتحديث المباشر لا |
| **Pro ‏$19/شهر** | ٧٥٠٠/يوم | **نعم بهامش خمسة أضعاف** |

وخطة Cloudflare Workers المجانية تعطي ١٠٠ ألف طلب يومياً — أي أن الوسيط نفسه
مجاني.

## التشغيل

كله من المتصفّح، بلا تثبيت شيء على جهازك:

**١. الأسرار الثلاثة** في `Settings ← Secrets and variables ← Actions`:

| السرّ | من أين |
|---|---|
| `CLOUDFLARE_API_TOKEN` | dash.cloudflare.com ← My Profile ← API Tokens ← قالب **Edit Cloudflare Workers** |
| `CLOUDFLARE_ACCOUNT_ID` | من صفحة Workers في اللوحة (العمود الأيمن) |
| `API_FOOTBALL_KEY` | dashboard.api-football.com بعد التسجيل |

> تُلصق في صفحة الأسرار مباشرة. لا تُرسل في أي محادثة ولا تُكتب في ملف داخل
> المستودع.

**٢. النشر:** تبويب Actions ← «نشر وسيط المباريات» ← Run workflow.

يختبر الإجراء منطق الوسيط أولاً، ثم يرفع المفتاح سرّاً إلى Cloudflare، ثم ينشر،
**ثم يسأل الوسيط عن يوم حقيقي ويعدّ المباريات** — فالنشر الناجح لا يعني وسيطاً
يعمل. وفي ملخّص التشغيل تجد الرابط.

**٣. تشغيله في التطبيقين:** ضع الرابط في
[`KoraTime/Tools/app-version.json`](../KoraTime/Tools/app-version.json):

```json
{ "matchesProxy": "https://koratime-matches.<حسابك>.workers.dev" }
```

وادفعه — فيصل التطبيقين **خلال دقيقة، بلا إصدار جديد ولا مراجعة من آبل**.
ولإطفائه أعِد القيمة فارغة.

## ما يفعله التطبيق

ثلاثة مسارات بالترتيب، وكلٌّ يسقط إلى ما بعده:

1. **مفتاح المستخدم الشخصي** إن وضعه في الإعدادات — حصّته وحده ولا يعتمد على
   خادمك.
2. **الوسيط** — وهذا ما يراه أغلب الناس.
3. **المصدر القديم** بحدوده المعروفة — شبكة أمان حين يسقط ما قبله.

فإطفاء الوسيط أو انقطاعه لا يترك أحداً بشاشة فارغة.

## الاختبار

```bash
cd Proxy && node worker.test.mjs
```

ستة عشر اختباراً بلا شبكة ولا مفتاح: التقليم، والتخزين (الطلب الثاني لا يمسّ
المصدر)، ورفض التواريخ الخاطئة والبعيدة، والسلوك بلا مفتاح، وترويسات CORS.
ويعمل الاختبار نفسه في إجراء النشر قبل الرفع، فالوسيط المعطوب لا يُنشر.

## الواجهة

```
GET /fixtures?date=YYYY-MM-DD   مباريات يوم، بشكل API-Football مقلَّماً
GET /health                     هل يرى الوسيط المفتاح؟
```

الاستجابة تحمل شكل API-Football نفسه لكن بالحقول التي يقرؤها التطبيقان فقط —
فيعمل المحلّل الموجود فيهما بلا تغيير، ويصغر الحِمل على شبكة الجوال إلى نحو
الثلث.
