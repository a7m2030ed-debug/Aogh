# مُفرِّغ البيانات

صفحة واحدة تأخذ **نموذجًا مفرَّغًا** وملف **إكسل**، وتُنتج نسخة معبَّأة لكل سجل — بصيغة **بوربوينت (.pptx)** أو **PDF**.

كل شيء يعمل داخل المتصفح: لا يُرفَع أي ملف إلى أي خادم، ولا تحتاج تثبيت أي شيء. افتح `index.html` وابدأ.

## الرابط العام

الصفحة تُنشر على GitHub Pages عند كل دفع للفرع، والرابط:

**https://a7m2030ed-debug.github.io/Aogh/**

يلزم تفعيل Pages مرة واحدة فقط من إعدادات المستودع:
**Settings → Pages → Build and deployment → Source: GitHub Actions**.
لا يمكن لسير العمل تفعيلها بنفسه لأن GitHub لا يمنح `GITHUB_TOKEN` صلاحية إنشاء موقع Pages.
بعد التفعيل، أعِد تشغيل سير العمل «Deploy to GitHub Pages» من تبويب Actions.

## طريقة الاستخدام

1. **ارفع ملف الإكسل** — اسحبه إلى المربع أو انقر لاختياره. الصيغ المدعومة: `xlsx` · `xlsm` · `csv` · `tsv`.
   السطر الأول في الملف يُعتبر أسماء الأعمدة، وكل سطر بعده سجلًا مستقلًا.
   إن لم يكن لديك ملف جاهز، اضغط **ملف إكسل تجريبي** لتنزيل ملف نموذجي ثم ارفعه.
2. **راجع النموذج** — تُربط خانات النموذج بأعمدة الملف تلقائيًا حسب تشابه الأسماء، وتنقّل بين السجلات بالأسهم لمعاينة كل واحد.
3. **حمِّل الناتج** — **تحميل PowerPoint** يُنشئ شريحة لكل سجل، و**تحميل PDF** يُنشئ صفحة لكل سجل عبر نافذة الطباعة (اختر «حفظ بصيغة PDF»).

## تحرير النموذج

- **إضافة خانة** — خانة تُربط بعمود من ملف الإكسل.
- **نص ثابت** — نص يظهر كما هو في كل نسخة، ويمكن دمج قيم داخله بكتابة `{{اسم العمود}}`
  مثال: `صرف لـ {{الاسم}} بتاريخ {{التاريخ}}`.
- **توليد من أعمدة الإكسل** — يبني خانات النموذج كاملة من أعمدة الملف المرفوع.
- **السحب والتحجيم** — اسحب أي خانة على الورقة لتغيير موضعها، واسحب المقبض الصغير في زاويتها لتغيير حجمها.
  اضغط `Shift` أثناء السحب لتعطيل المحاذاة إلى الشبكة، و`Delete` لحذف الخانة المحددة.
- **الخصائص** — العنوان، العمود المرتبط، حجم الخط، المحاذاة، الخط العريض، الإطار، وإحداثيات الخانة بالنسبة المئوية.

المقاسات المتاحة: شريحة عريضة ‎16:9‎، شريحة ‎4:3‎، و‏A4 عمودي أو أفقي. يُحفَظ النموذج في المتصفح تلقائيًا فتجده كما تركته عند العودة.

## إضافة أكثر من ملف

بتحديد **«إضافة السجلات للبيانات الحالية بدل استبدالها»** يُضاف كل ملف جديد إلى السجلات الموجودة بدل أن يحل مكانها،
وتُدمج الأعمدة المختلفة معًا — فالأعمدة الناقصة في أحد الملفين تظهر فارغة في سجلاته.

## ملاحظات تقنية

- لا توجد أي مكتبات خارجية. قراءة ملفات `xlsx` وكتابة ملفات `pptx` مبنية في الصفحة نفسها
  على `CompressionStream` / `DecompressionStream` المدمجة في المتصفح (كلا الصيغتين حاويات ZIP).
- يحتاج ذلك متصفحًا حديثًا (Chrome 103+، Edge 103+، Safari 16.4+، Firefox 113+).
  في المتصفحات الأقدم تعمل ملفات `csv` دون مشاكل.
- تُكتب الشرائح باتجاه من اليمين إلى اليسار (`rtl="1"`) وبخط Arial لضمان ظهور العربية صحيحة في بوربوينت.
- تواريخ الإكسل تُقرأ من تنسيق الخلية وتُحوَّل إلى `YYYY-MM-DD` بدل الرقم التسلسلي.
